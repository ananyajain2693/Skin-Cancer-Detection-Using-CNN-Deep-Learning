## 📌 Overview

Skin cancer is one of the most common forms of cancer worldwide, and early identification of suspicious lesions can play an important role in clinical workflows.

This project explores the use of **Convolutional Neural Networks (CNNs)** to classify skin-lesion images into two categories:

* 🟢 **Benign**
* 🔴 **Malignant**

The project includes the complete machine-learning workflow:

**Image preprocessing → Data augmentation → CNN training → Model evaluation → Model saving → Image prediction → Streamlit deployment**

The trained model is integrated into a simple web application where users can upload a `.jpg`, `.jpeg`, or `.png` skin-lesion image and receive a model prediction.

---

## ⚠️ Medical Disclaimer

**This project is intended for educational and research purposes only.**

The model is **not a medical device and must not be used to diagnose, treat, or rule out skin cancer**. Predictions generated by this application should not replace examination by a qualified dermatologist or other healthcare professional.

Real-world clinical deployment would require extensive external validation, appropriate regulatory review, clinical testing, bias assessment, calibration, and evaluation across diverse patient populations and imaging conditions.

## ✨ Key Features

* 🧠 CNN-based binary image classification
* 🖼️ 224 × 224 image preprocessing
* 🔄 Training-time image augmentation
* ⚖️ Pixel normalization to the `[0, 1]` range
* 🎯 Binary classification using sigmoid activation
* 🛑 Early stopping to reduce unnecessary training
* 📉 Learning-rate reduction when validation loss plateaus
* 📊 Classification report and confusion matrix evaluation
* 💾 Saved Keras `.h5` model
* 🌐 Interactive Streamlit application
* 📤 Upload-and-predict workflow

The application preprocesses uploaded images to 224×224 pixels, normalizes their pixel values, and applies a 0.5 prediction threshold for the final class label.

# 🧠 CNN Model

The implemented model consists of three convolutional blocks followed by fully connected layers.

| Layer        | Configuration          |
| ------------ | ---------------------- |
| Input        | `224 × 224 × 3`        |
| Conv2D       | 32 filters, 3×3, ReLU  |
| MaxPooling2D | 2×2                    |
| Conv2D       | 64 filters, 3×3, ReLU  |
| MaxPooling2D | 2×2                    |
| Conv2D       | 128 filters, 3×3, ReLU |
| MaxPooling2D | 2×2                    |
| Flatten      | —                      |
| Dense        | 512 units, ReLU        |
| Dropout      | 0.5                    |
| Output       | 1 unit, Sigmoid        |

The notebook compiles the network using the **Adam optimizer**, **binary cross-entropy loss**, and **accuracy** as the training metric.

# 📊 Dataset

The training notebook uses a directory-based image dataset with two classes:

```text
dataset/
├── train/
│   ├── Benign/
│   └── Malignant/
│
└── test/
    ├── Benign/
    └── Malignant/
```

The notebook reports:

* **11,879 training images**
* **2,000 test images**
* `Benign → 0`
* `Malignant → 1`

Images are resized to **224×224** before being supplied to the network.

---

# 🔄 Data Preprocessing & Augmentation

Training images are normalized and augmented using transformations including:

* Rotation
* Width shifting
* Height shifting
* Shearing
* Zooming
* Horizontal flipping

Testing images are normalized without the training augmentation transformations.

This helps the CNN learn representations that are less sensitive to small variations in image orientation and positioning.

---

# 🏋️ Training

The model is configured for up to **30 epochs**.

Two callbacks are used:

### EarlyStopping

Training monitors validation loss and stops when the model no longer improves, while restoring the best-performing weights.

### ReduceLROnPlateau

The learning rate is reduced when validation loss stops improving, allowing the model to make smaller optimization steps during later training.

The trained model is saved as:

```text
skin_cancer_cnn.h5
```

# 🔬 Example Prediction

```python
from tensorflow.keras.preprocessing import image
from tensorflow.keras.models import load_model
import numpy as np

model = load_model("skin_cancer_cnn.h5")

img = image.load_img(
    "sample.jpg",
    target_size=(224, 224)
)

img_array = image.img_to_array(img) / 255.0
img_array = np.expand_dims(img_array, axis=0)

prediction = model.predict(img_array)

label = "Malignant" if prediction > 0.5 else "Benign"

print(f"Prediction: {label}")
```

# 📌 Limitations

This project has several important limitations:

1. **Binary classification does not represent the full range of skin lesions or skin cancers.**
2. Model performance can be affected by image quality, lighting, acquisition device, lesion location, and demographic variation.
3. A high test accuracy alone does not establish clinical usefulness.
4. The current training workflow uses the test generator during training as validation data, so a stronger experimental design should reserve an independent validation set and keep the final test set untouched until the end.
5. The model has not been established as clinically validated.
6. Predictions should not be interpreted as medical diagnoses.
7. External validation on an independent dataset is required before making claims about generalization.
